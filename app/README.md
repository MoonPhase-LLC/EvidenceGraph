# EvidenceGraph Desktop Shell

Tauri v2 desktop application shell with a React + TypeScript frontend
(Tailwind CSS v4 + shadcn/ui configured). This currently renders a placeholder
screen only — see the root [`CONTRIBUTING.md`](../CONTRIBUTING.md) for exact
setup/build commands, toolchain versions, and Windows prerequisites, and
[`docs/SPRINT_1_BACKLOG.md`](../docs/SPRINT_1_BACKLOG.md) S1-02 for this
ticket's scope.
